# AI disclosure — Game Off 2026

In the spirit of the jam's disclosure guidance:

- **Code:** AI coding tools were used for drafting, debugging, refactoring,
  and documentation assistance. The author reviewed and integrated the final
  code and is responsible for it.
- **Visual assets:** Some character, plant, and prop images are AI-assisted
  (Jimeng AI), with commercial authorization documented in
  [ASSET_LICENSES.md](ASSET_LICENSES.md).
- **Audio:** Licensed music and sound effects from Pixabay and Kenney; no
  runtime generative audio.
- **Runtime:** The game does not call any generative AI service at runtime and
  does not send player data to an AI service.

This disclosure is provided so players and jam organizers can evaluate the
entry accurately.
